## Why Annotaat

- **Out of source**: notes live in `.vscode/annotations/{branch}.json`, never pollute your code
- **Per-branch**: switch branches, annotations follow. Pull from another branch in one command
- **One keystroke**: `Cmd+Opt+A` / `Ctrl+Alt+A` to annotate any selection
- **Exportable**: full Markdown report for PRs, reviews, or to hand to your AI agent

## About this repository

This is the **companion repo** for Annotaat. The extension itself is distributed via the [VS Code Marketplace](https://marketplace.visualstudio.com/items?itemName=avrebarra.annotaat-plugin) and the source is not public.

**What belongs here:**

- Bug reports (highlight not showing, anchor broken, export formatting)
- Feature requests and UX ideas
- Questions and general discussion

**What doesn't belong here:**

- Source pull requests, there is no source to PR against
- Private support, use an issue so others can find it

All feedback is triaged here. Good reports get reused as acceptance criteria.

## Quickstart

No clone or build needed.

1. Install from the [VS Code Marketplace](https://marketplace.visualstudio.com/items?itemName=avrebarra.annotaat-plugin)
2. Select code, press `Cmd+Opt+A` (Mac) / `Ctrl+Alt+A` (Win/Linux)
3. Write your note, it appears in the Annotaat sidebar and the range gets highlighted in the editor

See the on-marketplace README for full feature docs.

## How to contribute

1. **Search** existing [issues](https://github.com/avrebarra/annotaat/issues) first, maybe it's already reported
2. **Open an issue** via [New Issue → Choose a template](https://github.com/avrebarra/annotaat/issues/new/choose), pick bug report or feature request
3. For open-ended ideas, start a [Discussion](https://github.com/avrebarra/annotaat/discussions)

A good report has: **what you did → what you expected → what happened**, plus `Annotaat version`, `VS Code version` (`Help → About`), `OS`, and a screenshot if visual. See [CONTRIBUTING.md](./CONTRIBUTING.md) for the full guide.
